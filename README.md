# dotfiles

Personal macOS / Debian development environment — zsh, tmux, Neovim, modern CLI
tooling, and an AI-first workflow built around Claude Code.

## Setup

```sh
git clone https://github.com/imaqsood/dotfiles.git ~/dev/dotfiles
cd ~/dev/dotfiles && ./bootstrap.sh
```
